# Как работать с репозиторием

У нас есть 3 типа веток
- `main` - стабильная версия программы
- `dev` - версия программы, активно разрабатываемая
- `feat-[name]-[id]` - ветка для работы над отдельной задачей

## Процесс разработки фичи
### 1. Создаем ветку feature (3 ветка из типов веток).

Называем ее `feat-[name]-[id]`, где `name` - краткое название фичи, а `id` - ID задачи из таск трекера

### 2. Реализуем функционал

Решаем задачу, которую поставили в задаче из таск трекера

### 3. Отправляем на ревью

**Перед тем, как отправить на ревью, мерджим ветку dev в вашу ветку фичи.** - это очень важно

Когда все сделано, и закоммичено в ветку feature, переносим задание в таск трекере в статус **ревью**.


Также в карточке задания прикрепляем ссылку на ветку, описываем что сделано.

Можно уведомить других людей.

### 4. Мердж ветки

Мерджить ветку будет проверяющий, после чего он передвинет задачу в статус **завершено**. На этом этапе жизненный цикл задачи завершен.
